# KiGo — лендинг

Главная страница KiGo (Bosh sahifa), сверстанная на React + Vite по дизайну канваса «KiGo UI dizayn».

```bash
npm install
npm run dev     # http://localhost:5173
npm run build   # сборка в dist/
```

- `src/components/` — секции страницы
- `src/index.css` — стили и цветовые токены
- `public/images/` — изображения
